# CodeAlpha Stock Portfolio Tracker

A simple Python program that calculates the total investment value of selected stocks.

### Features
- Manually defined stock prices using a Python dictionary
- User enters stock name and quantity
- Calculates investment for each stock
- Displays the total investment value
- Handles invalid stock names and quantities
- Uses basic input/output, dictionary, loops, conditions and arithmetic

### Technologies
- Python

### How to Run

1. Install Python.
2. Open the project folder in VS Code or CMD.
3. Run:

```bash
python stock_portfolio_tracker.py
```

### Example
